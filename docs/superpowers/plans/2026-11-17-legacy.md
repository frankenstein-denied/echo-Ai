# Legacy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an Echo owner name inheritors who, after the owner has been inactive for a chosen number of months, answer a one-word question to open the owner's shared memories and chat with a first-person memorial Echo that types like the owner.

**Architecture:** There is no admin SDK (`firebase-admin` doesn't bundle on Vercel), so every protection — release by inactivity, the hidden answer, the rate limit, what each inheritor may read — is enforced in `firestore.rules` with `get()` and timestamp + `duration.value` arithmetic. Clients read and write Firestore directly. Two new server routes call Gemini: one builds the owner's voice profile, one answers in the owner's voice. Pure logic lives in `lib/echo/legacy*.ts` and is unit-tested with vitest.

**Tech Stack:** Next.js 16.4 (read `node_modules/next/dist/docs/` before touching routes, per AGENTS.md), React 19, Firebase JS SDK 13 (Firestore + Auth), `@google/genai`, vitest 5, Tailwind 4, existing `components/echo/ui` primitives.

**Spec:** `docs/superpowers/specs/2026-11-17-legacy-design.md` (read it; it is the authority).

## Global Constraints

- Inheritors are Echo users added by email; request → accept; max **5** inheritors per owner (UI-enforced).
- At least **12** preset questions with stable ids `q1`…`q12`; never reorder or reuse an id.
- Answer: trimmed, NFC, `toLowerCase()` (never `toLocaleLowerCase`), one word matching `^[\p{L}\p{N}'-]{1,40}$`u. `answerHash = sha256hex(linkId + ':' + normalized)` via WebCrypto.
- Link id is `${ownerUid}_${inheritorUid}`.
- Release: `enabled && request.time > lastActiveAt + duration.value(releaseAfterMinutes, 'm')`. UI months 1–24 → `months * 30 * 1440` minutes. Rules accept 5 … 1,051,200. "5 minutes" option only when `process.env.NEXT_PUBLIC_LEGACY_DEMO === '1'`.
- `lastActiveAt` stamped at most once per hour on app open, focus, and chat send; must equal `request.time`.
- Guesses: max **5** per **24 h** window; `correct` forced by rules to equal `guessHash == secret.answerHash`.
- `legacySecrets` readable by **nobody**.
- Share kinds: `life` (person, interest, topic, trait, connector, task, diary memories), `goals` (goal memories + `goals`), `notes`, `diary` (`diaryPages` only, never messages), `health` (health memories + `healthLogs` + `meals`). Default: all on except `health`.
- Memorial chat: first person, owner's language/typing style, uses only provided memories, never invents; returns 1–4 bubbles; label "✨ remembered by Echo · tap for info" always visible.
- Inheritor UI never shows a countdown or the owner's `lastActiveAt`.
- Never refer to the owner with gendered pronouns in UI copy or prompts; use their name or "they".
- Do **not** deploy rules or push; the owner deploys `firestore.rules` before the app (memory: rules-deploy-order).

## Review Focus

1. Answer typed with different case or surrounding spaces ("  Bantay ") must match "bantay" — pinned in Task 1 tests.
2. Owner returns after release → access closes (rules compute Released live) — rules text check in Task 2 + manual QA note.
3. Owner removes then re-adds the same inheritor → must answer again — `removeInheritor` / `addInheritor` delete attempts, asserted in Task 3 tests.
4. Gemini returns malformed JSON or >4 bubbles or empty → chat shows a gentle in-character fallback, never crashes — Task 4 sanitizer tests.
5. Adding an email with no directory entry, or one's own email, or a 6th inheritor → clear error, nothing written — Task 3 tests on `validateNewInheritor`.

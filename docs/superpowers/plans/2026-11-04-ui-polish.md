# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carry the 2nd Brain's orb color language across Echo: glow cards, a living "Today's orb" on new pages, Health as two filling bodies, and a landing hero of floating memory orbs.

**Architecture:** Pure helpers (colors, fill levels, labels) live in `lib/echo/*.ts` with vitest tests. Small presentational components live in `components/echo/*` and reuse `MemoryOrb`, `OrbSwatch`, `orbSwatchStyle` and `ORB_COLOR` from the shipped orbs work. Each screen is then wired to them.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind 4, Firebase client SDK, vitest. Playwright (scratchpad only) for visual checks.

**Spec:** `docs/superpowers/specs/2026-11-04-ui-polish-design.md`. It is the authority, including its "Answers to the builder check" section.

## Review Focus
1. **Water at or beyond the target** (8, 12, or a negative or NaN value): the body is full (clamped to 0..1) and the text reads `12 / 8 glasses · goal reached`, never "-4 to go". *(Task 4 tests.)*
2. **Calories with no goal, zero meals, or calories disabled:** no goal → the body is scaled to 2,000 kcal and the text is `1,350 kcal today` plus a "Set a goal" link. 0 kcal → an empty body, not NaN. Disabled → only the water body renders. *(Task 4 tests + Task 5 rendering.)*
3. **Tags that differ in case or spacing from a person's label** (`" ana "` vs `Ana`) still turn rose; an empty or whitespace tag never does. *(Task 1 tests.)*
4. **A brand-new page with no Firestore doc yet:** the Today's orb shows a breathing pearl and doesn't crash or flash a loading error. *(Task 3 test on `emptyPageOrb`.)*
5. **Reduced motion:** no wave, breathing, drift or fill animation anywhere, and fills jump straight to their level. *(Each UI task's visual check uses `page.emulateMedia({ reducedMotion: 'reduce' })` once.)*

### Task 1: Glow helpers and primitives

**Files:**
- Create: `lib/echo/glow.ts`, `lib/echo/glow.test.ts`, `components/echo/glow.tsx`

**Interfaces:**
- Consumes: `ORB_COLOR`, `OrbKind`, `PEARL` from `lib/echo/orbs.ts`; `OrbSwatch` from `components/echo/memory-orb.tsx`.
- Produces (lib/echo/glow.ts):
  - `WATER_DEEP = '#1d4ed8'`, `WATER_COLOR = '#38bdf8'`, `KCAL_FROM = '#c2410c'`, `KCAL_TO = '#fbbf24'`, `OVER_GLOW = '#ef4444'`
  - `kindForCategory(category: string | undefined): OrbKind | null`. Maps note→note, goal→goal, reminder→reminder, health→health, meal→health, case-insensitive; anything else → null.
  - `personLabelSet(labels: (string | undefined)[]): Set<string>`. Holds lowercased, trimmed, non-empty labels.
  - `isPersonTag(tag: string, people: Set<string>): boolean`
  - `glowCardStyle(kind: OrbKind): React.CSSProperties`. Corner light: `radial-gradient(120% 90% at 100% 0%, color-mix(in srgb, <color> 20%, transparent), transparent 60%)` layered over `var(--color-surface)`, plus `borderColor: color-mix(in srgb, <color> 30%, var(--color-border))`.
  - `tagStyle(kind: OrbKind): React.CSSProperties`. Background is the color at 16%, text is the kind color, border the color at 35%.
  - `timeChipLabel(at: Date, now: Date): string`. Today → `3:00 PM`, tomorrow → `Tomorrow 3:00 PM`, otherwise `Nov 6, 3:00 PM` (en-US, local time).
- Produces (components/echo/glow.tsx):
  - `GlowDot({ kind, size = 12 }: { kind: OrbKind; size?: number })`. An `OrbSwatch` with a single-kind count.
  - `KindTag({ kind, children }: { kind: OrbKind | null; children: ReactNode })`. Tinted when `kind` is set, otherwise the existing neutral `Badge` look.
  - `ProgressRing({ value, size = 36, color = ORB_COLOR.goal, label }: { value: number; size?: number; color?: string; label: string })`. `value` 0..100 is clamped. An SVG ring with a faint drop-shadow glow; `role="img"`, `aria-label={label}`.
  - `TimeChip({ at, state }: { at: Date; state: 'upcoming' | 'overdue' | 'done' })`. Upcoming is amber, overdue uses `var(--color-danger)`, done is muted. Shows a clock icon (lucide `Clock`) and `timeChipLabel`.

### Task 4: Health fill math

**Files:**
- Create: `lib/echo/body-fill.ts`, `lib/echo/body-fill.test.ts`

**Interfaces:**
- Produces:
  - `WATER_TARGET = 8`, `NO_GOAL_KCAL_SCALE = 2000`
  - `waterFill(glasses: number): { level: number; full: boolean; text: string; sub: string }`. `level = clamp(g / 8, 0, 1)` with NaN or negative → 0; `text = '<g> / 8 glasses'`; `sub` = `'<8-g> to go'`, or `'goal reached'` when g ≥ 8.
  - `calorieFill(kcal: number, goal: number | undefined): { level: number; over: boolean; noGoal: boolean; text: string; sub: string }`. With a goal: `level = clamp(kcal / goal, 0, 1)`, `over = kcal > goal`, `text = '1,350 of 2,000 kcal'`, `sub = '650 left'` or `'200 over'`. Without a goal: `level = clamp(kcal / 2000, 0, 1)`, `noGoal: true`, `text = '1,350 kcal today'`, `sub = ''`. Numbers use en-US grouping and are rounded; NaN or negative kcal → 0.
  - `averageLogged(values: (number | null | undefined)[]): number | null`. The mean of finite values only, or null when there are none.

# Echo Legacy engine — batch 2 (2.06/2.07, 2.09, 2.12) — design

Date: 2026-11-28 · Status: approved by the owner on 2026-11-28 ("leave 1.09 for now"; the rest as proposed)
Team: Peter Paul Poloan — Front End, Back End, Q/A, UI/UX Designer, Documentator (one-member group)

## Scope
- **2.12** lexer tests: at least 10 cases, one clearly named test per criterion (valid tokens, dates, quoted strings, comments, blank lines, unknown symbols, unterminated strings); a criterion → test table in the test plan.
- **2.06 / 2.07** (identical text in Kaneo; treated as one piece of work until the owner says what 2.07 is): Prolog fact structure for people, protocols, entries, tags, grants; first rules: nothing by default, three levels; loads from the main program; at least five access-table rows pass.
- **2.09** high-fidelity screens for all owner and asker screens, a style guide, and an error-message catalog with one message per error type; denied-access messages never reveal that an entry exists.
- **Not now:** 1.09 (studio app skeleton) and 2.08 (owner screens, which need 1.09).

## Decisions
- Prolog facts (`prolog/access_rules.pl`): `person(P)`, `protocol(P)` (P has a protocol), `entry(E, date(Y,M,D), Kind)`, `tag(E, T)`, `mentions(E, P)`, `grant(P, Level, Selector)`, `deny(P, Level, Selector)`, `letter(E, Title, Recipient, date(Y,M,D))`. Selectors `tag(T)`, `mentions(P)`, `letter(Title)`. Rules: `can_see(P, Level, E)` requires `person(P)`, `protocol(P)`, an allow that reaches Level, and no deny that reaches Level; levels existence < summary < full; allow reaches weaker levels, deny reaches stronger levels (same semantics as the TypeScript model). Release dates and the death trigger stay for a later ticket; full access to a letter is not granted by these rules yet (only `summary`/`existence` of a letter).
- TypeScript `engine/src/prolog/facts.ts`: turns entries + a protocol list into fact strings with safe quoting (atoms quoted with single quotes, escaping `\` and `'`).
- Access-table tests: `tests/engine/access-table.test.ts` reads `project-docs/05-access-test-table.csv`, runs the rows these rules can decide (M1, M2, M5, M6, A1, A3, A4) through Prolog with the fictional fixture plus the handout policy as facts; at least 5 must pass. Rows needing release dates/death trigger (M3, M4, A2) and the AI (A5) are skipped with a reason.
- Old starter facts `entry(Id, Tags, Mentions)` are replaced; the bridge test and demo are updated.
- 2.09: `project-docs/09-style-guide.md` (tokens from `app/globals.css`, type scale, spacing, radii, components); `project-docs/10-error-messages.md` + `engine/src/messages.ts` (`messageFor(error)`); hi-fi SVGs in `project-docs/11-hifi/` generated by an upgraded `scripts/project-docs/gen-hifi.mjs` (real icon paths, full content, states), PNG previews.
